# Security & privacy

## What the app stores

All data stays in the browser's `localStorage` on the user's device. There is no server, account, analytics or tracking. Optional sync stores data only in the user's own Google Drive `appDataFolder` and needs their explicit sign-in.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/FahadKhalid/cash-flow/security/advisories/new)
on this repository. You'll get a reply as soon as possible.

## Scope

In scope: script injection, data leaking off the device, sync merge bugs that lose data, unsafe handling of imported files.
